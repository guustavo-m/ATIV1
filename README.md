# 🧪 Atividade 1 — Testes de Software

Projeto de exercícios em JavaScript para praticar testes unitários com Jest. Os testes verificam funções utilitárias de cálculos, validações e manipulação de dados.

## 📋 Funcionalidades testadas

- Verificação de maioridade;
- Cálculo do Índice de Massa Corporal (IMC);
- Formatação de nome e sobrenome;
- Verificação de número par;
- Conversão de Celsius para Fahrenheit;
- Adição de um hobby sem alterar a lista original;
- Divisão, incluindo o tratamento de divisão por zero;
- Criação de um objeto de aluno;
- Aplicação de desconto;
- Validação do tamanho mínimo de uma senha.

## 📦 Requisitos

- Node.js e npm.

## ⚙️ Instalação

Na pasta do projeto, instale as dependências:

```bash
npm install
```

## ▶️ Executar os testes

Para executar a suíte de testes com Jest:

```bash
npm test
```

Os casos de teste estão em `sistema.test.js`, e as funções verificadas estão implementadas em `sistema.js`.
